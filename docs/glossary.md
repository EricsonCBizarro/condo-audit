# Glossary (Portuguese → English)

The code is in English; the documents it reads are in Brazilian Portuguese.

| Portuguese | In the code | Meaning |
|---|---|---|
| condomínio | condominium | the building's legal entity |
| condômino | owner / resident | unit owner |
| síndico(a) | manager | elected building manager |
| administradora | property manager | company hired to run the books |
| balancete | financial statement | monthly report: bank extract + receipts |
| extrato | statement | bank account lines with running balance |
| saldo anterior / final | opening / closing balance | |
| comprovante, recibo | receipt | proof of a payment |
| previsão orçamentária | budget | approved monthly amounts per category |
| assembleia (AGO / AGE) | meeting (ordinary / extraordinary) | owners' assembly |
| edital de convocação | meeting notice | agenda published before a meeting |
| ata | minutes | record of what the assembly decided |
| convenção | convention | founding rules (e.g. spending limits) |
| regimento interno | bylaws | house rules and penalties |
| advertência / multa | warning / fine | penalty steps |
| CNPJ | tax id | company registration number |
